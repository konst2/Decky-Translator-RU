# Значения настроек по умолчанию

Описание ключей из `settings_defaults.json`. В JSON нельзя писать комментарии, поэтому пояснения здесь.

Файл с умолчаниями: **`py_modules/settings_defaults.json`**. Это единственное место, где их задают. Бэкенд читает его через `py_modules/settings_defaults.py`, фронтенд встраивает в сборку через `src/settingsDefaults.ts`. Значения во фронтенде обновятся после `pnpm build`.

## Почему файл лежит в `py_modules/`

Файл должен попасть в плагин при любой сборке. Плагин собирает Decky CLI, а сборка для магазина Decky идёт только через него, без наших шагов CI. CLI упаковывает фиксированный набор путей (`dist`, `main.py`, `py_modules/` и т. п.). Каталог вроде `settings/` в него не входит: в магазинной сборке файла бы не оказалось, и бэкенд не запустился бы.

`py_modules/` почти целиком в `.gitignore`: туда ставятся зависимости. Файл и его загрузчик внесены в `.gitignore` исключениями (`!py_modules/settings_defaults.json`, `!py_modules/settings_defaults.py`). Новый файл рядом с ними git молча проигнорирует.

Ключи — имена настроек в файле настроек плагина (snake_case). Во фронтенде у них camelCase-имена: `hold_time_translate` → `holdTimeTranslate`.

Умолчание действует, пока пользователь не поменял настройку. Сохранённое значение важнее. Поэтому новое умолчание увидят новые установки и те, кто эту настройку не трогал.

Новая настройка: добавить ключ в JSON, строку сюда и правило в `tests/test_settings_defaults.py`. Тест проверяет, что ключи JSON совпадают с тем, что `main.py` отдаёт фронтенду, что значения допустимые, что у каждого ключа есть строка здесь и что значение в колонке «Значение» совпадает с JSON (записано так же, как в JSON).

Ключей API (`google_api_key`, `gemini_api_key`, `yandex_api_key`, `yandex_folder_id`, `gigachat_api_key`) и `mymemory_email` здесь нет намеренно. Это данные пользователя, а не умолчания: пустая строка у них значит «не введено».

## Общие

| Ключ | Значение | Что это |
|---|---|---|
| `enabled` | `true` | Плагин включён (переключатель на главной вкладке). |
| `debug_mode` | `false` | Режим отладки: подробный лог и панель диагностики. |

## Языки и методы

| Ключ | Значение | Что это |
|---|---|---|
| `input_language` | `"en"` | Язык текста в игре (с какого переводим). |
| `target_language` | `"ru"` | Язык перевода. Им же по умолчанию пользуется Gemini Vision. |
| `ocr_provider` | `"chromescreenai"` | Метод распознавания: `chromescreenai`, `rapidocr`, `ocrspace`, `googlecloud`, `gemini_vision`. |
| `translation_provider` | `"mymemory"` | Метод перевода: `mymemory`, `freegoogle`, `googlecloud`, `yandex`, `gigachat`, `gigachat_plus`, `ct2` (NLLB), `opusmt`. MyMemory выбран, потому что работает из России без ключа. Исключение на первом запуске: при OCR `googlecloud` метод перевода тоже `googlecloud`. |
| `gemini_model` | `"gemini-2.5-flash"` | Модель Gemini для метода Gemini Vision. |
| `translation_cache_enabled` | `true` | Кэшировать переводы: повторный текст не уходит в сервис заново. |

## Управление

| Ключ | Значение | Что это |
|---|---|---|
| `input_mode` | `0` | Горячая клавиша перевода, номер из `InputMode` в `src/Input.tsx`: 0 — L4, 1 — R4, 2 — L5, 3 — R5, 4 — L4+R4, 5 — L5+R5, 6 — два тачпада, 7 — L3, 8 — R3, 9 — L3+R3. |
| `hold_time_translate` | `500` | Сколько **миллисекунд** держать кнопку, чтобы запустить перевод. Полсекунды: L4 игры почти не используют, случайных срабатываний мало, а ждать каждую секунду при каждом переводе утомительно. |
| `hold_time_dismiss` | `500` | Сколько **миллисекунд** держать кнопку, чтобы закрыть оверлей. |
| `quick_toggle_enabled` | `false` | Быстрое переключение правой кнопкой: в режиме из двух кнопок короткое нажатие правой показывает и скрывает оверлей. |
| `pause_game_on_overlay` | `false` | Ставить игру на паузу, пока открыт перевод. |

## Распознавание

| Ключ | Значение | Что это |
|---|---|---|
| `custom_recognition_settings` | `false` | «Настройка распознавания». Пока выключено, бэкенд при старте не применяет сохранённые пороги `confidence_threshold` и `rapidocr_*` (кроме `*_persistent_mode`), а работает с умолчаниями. |
| `confidence_threshold` | `0.6` | Порог уверенности, 0–1: распознанные строки ниже порога отбрасываются. Ползунок показан только для Google Cloud, а фильтр сейчас срабатывает для всех методов распознавания. |
| `rapidocr_confidence` | `0.5` | RapidOCR: минимальная уверенность строки, 0–1. |
| `rapidocr_box_thresh` | `0.5` | RapidOCR: порог обнаружения областей с текстом, 0–1. Ниже — больше областей. |
| `rapidocr_unclip_ratio` | `1.6` | RapidOCR: расширение рамок вокруг текста, 1–3. |
| `rapidocr_persistent_mode` | `false` | «Быстрое распознавание» для RapidOCR: держать движок в памяти между переводами. |
| `chromescreenai_persistent_mode` | `false` | «Быстрое распознавание» для Chrome Screen AI: держать движок в памяти между переводами. |
| `ct2_persistent_mode` | `false` | «Быстрый перевод» для локальных моделей (NLLB, Opus-MT): держать модель в памяти между переводами. |
| `grouping_power` | `0.25` | Группировка текстовых блоков, шаг 0.25: 0.25 — блоки не объединяются, 1.0 — объединяются даже далёкие. |

## Вид перевода

| Ключ | Значение | Что это |
|---|---|---|
| `font_scale` | `1.0` | Множитель размера шрифта перевода. |
| `translated_text_alignment` | `"left"` | Выравнивание текста в подписи: `left`, `right`, `center`, `justify`. Левый край выбран, потому что так лучше читаются меню, списки и длинные реплики, а подпись может расти вправо. |
| `translated_text_font_family` | `""` | Шрифт перевода. Пустая строка — шрифт по умолчанию (Noto Sans / DejaVu Sans). |
| `translated_text_font_style` | `"normal"` | Начертание: `normal`, `bold`, `italic`, `bolditalic`. |
| `hide_identical_translations` | `false` | Не показывать подпись, если перевод совпал с оригиналом. |
| `allow_label_growth` | `true` | Разрешить подписи расти за пределы исходного блока, если перевод не помещается. |
